Steel, rust, brass

Danger is deliberately off-hue from the accent. Rust sits at 15° and crimson at 356°. When they match, a destructive button and the primary action become the same colour and the only thing separating them is the label. Warning is likewise pulled brighter than brass so a caution notice cannot be mistaken for a price.

Every hex and ratio on this page is read from the live tokens at load, not typed in. Ratios are measured against --surface-base unless noted, so switching the theme re-measures rather than lying.

Thirteen roles, no improvising

The current site stylesheet declares "Iowan Old Style", "Palatino Linotype", Palatino, Georgia, serif with no webfont loaded anywhere in the repo. macOS gets Iowan, Windows gets Palatino, Linux and Android fall back to Georgia — the intended headings have never actually shipped to most visitors. The three fonts on this page are self-hosted from public/assets/fonts/, so they render identically everywhere.

03 — Buttons

Five variants, five states each

One rust button per view. If a screen has three, it has no primary action. Every variant defines rest, hover, active, focus, and disabled — a missing focus ring means the component is unfinished.

04 — Form elements

Sunken means editable

Cards are raised, fields are sunken. That inversion is the whole signal that something accepts input. Labels sit above the field — placeholder text is never the label.
